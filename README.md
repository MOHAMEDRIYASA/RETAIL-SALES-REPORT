# RETAIL-SALES-REPORT
📊 Retail Sales Report Dashboard | Power BI Project

I'm excited to share my Retail Sales Report Dashboard, developed using Microsoft Power BI to transform sales data into meaningful business insights.

🔹 Key Highlights:

- 📈 Sales and Profit Analysis
- 💰 Total Sales, Total Profit & Profit Margin KPIs
- 🛒 Customer Segment & Product Performance Analysis
- 🌍 Region-wise Sales Comparison
- 📅 Monthly Sales Trend Analysis
- 📊 Category-wise Sales Contribution
- 🎯 Interactive Filters and Slicers for dynamic analysis

🛠️ Tools Used: Microsoft Power BI, Data Visualization, Interactive Dashboards & Business Intelligence.

This project helped me strengthen my analytical thinking, data visualization, and reporting skills while understanding how data can support better business decisions.
